# Data sources

Everything the keyboard ships is either written for this project or built from a source that
allows redistribution. Nothing is downloaded by the app at runtime; the app has no internet
permission at all.

## Bangla word list (`app/src/main/assets/banglish/lexicon.bin`)

| Field | Value |
|---|---|
| Source | `hermitdave/FrequencyWords`, Bengali subtitle corpus, 2018 release |
| URL | https://github.com/hermitdave/FrequencyWords/blob/master/content/2018/bn/bn_full.txt |
| Licence | MIT |
| Attribution | Copyright (c) 2016 Hermit Dave |
| Downloaded | build time only, by `tools/build_banglish_lexicon.py`; the raw file never enters the repo |
| Transform | Bengali-only words, junk filtered, NFC normalised, indexed by skeleton |
| Output | 83,433 word forms under 73,992 skeletons, 2.7 MB, one tab-separated line per word |

The list is a frequency table from film and television subtitles. It is good at everyday
spoken words and weak on formal or technical vocabulary, which is exactly the balance a
messaging keyboard wants. Words that appear once are kept: they are rare, not wrong, and the
ranker sorts them last.

Filtering rules applied by the builder, all documented in the script:

* only code points in the Bengali block, so Latin, digits and punctuation never get in;
* no word starting with a kar sign or a hasanta, and none ending on a hasanta;
* no independent vowel followed by another vowel, a kar sign or a hasanta — those are
  subtitle typos such as `আাবার` for `আবার`, and they used to poison the suggestions.

## Banglish rules (`app/src/main/assets/banglish/phonetic_rules.json`)

Written for this project, following the publicly documented Avro Phonetic scheme. See
[`BANGLISH.md`](BANGLISH.md).

## Skeleton rules (`app/src/main/assets/banglish/skeleton_rules.json`)

Written for this project. Read by both the build tool and the app so the two can never
disagree about what a word's canonical spelling is.

## Accuracy corpus (`app/src/test/resources/banglish_cases.tsv`)

Generated by `tools/build_banglish_lexicon.py` from the word list above plus a hand-written
curated list of the words a learner types first. Every generated Roman spelling is checked to
read back to the same skeleton, so the corpus cannot contain a case that is unreachable by
construction.

## Rebuilding

```powershell
python tools/build_banglish_lexicon.py
.\gradlew.bat testDebugUnitTest
```

The script downloads the source into `build/banglish/` once, then writes both the asset and
the test corpus. The accuracy test prints top-1 and top-5 numbers and fails below 80% and 95%.
