# Data sources

Everything the keyboard ships is either written for this project or built from a source that
allows redistribution. Nothing is downloaded by the app at runtime; the app has no internet
permission at all.

## Bangla word list (`app/src/main/assets/banglish/lexicon.bin`)

| Field | Value |
|---|---|
| Source | `hermitdave/FrequencyWords`, Bengali subtitle corpus, 2018 release |
| URL | https://github.com/hermitdave/FrequencyWords/blob/master/content/2018/bn/bn_full.txt |
| Licence | Content CC BY-SA 4.0 (upstream code is MIT) |
| Attribution | Copyright (c) 2016 Hermit Dave |
| Downloaded | build time only, by `tools/build_banglish_lexicon.py`; the raw file never enters the repo |
| Transform | Bengali-only words, junk filtered, NFC normalised, indexed by skeleton |
| Output | 83,433 word forms under 73,992 skeletons, 2,722,307 bytes, one tab-separated line per word |

The list is a frequency table from film and television subtitles. It is good at everyday
spoken words and weak on formal or technical vocabulary, which is exactly the balance a
messaging keyboard wants. Words that appear once are kept: they are rare, not wrong, and the
ranker sorts them last.

Filtering rules applied by the builder, all documented in the script:

* only code points in the Bengali block, so Latin, digits and punctuation never get in;
* no word starting with a kar sign or a hasanta, and none ending on a hasanta;
* no independent vowel followed by another vowel, a kar sign or a hasanta — those are
  subtitle typos such as `আাবার` for `আবার`, and they used to poison the suggestions.

## Banglish rules (`app/src/main/assets/banglish/phonetic_rules.json`)

Written for this project, following the publicly documented Avro Phonetic scheme. See
[`BANGLISH.md`](BANGLISH.md).

## Skeleton rules (`app/src/main/assets/banglish/skeleton_rules.json`)

Written for this project. Read by both the build tool and the app so the two can never
disagree about what a word's canonical spelling is.

## Packed reverse index (`app/src/main/assets/banglish/reverse.bin`)

Built offline from the existing lexicon plus `tools/data/local_words.tsv` by
`tools/build_reverse_index.py`. It contains 82,816 NFC-unique words, 333,039 sorted
Roman references and 6,952,901 bytes. Words repeated under different skeletons in
the legacy file are deduplicated. Common aliases are generated with bounded variation;
the builder never reads test fixtures or downloads text.

The big-endian `SRI1` format starts with the word count, length-prefixed UTF-8
word/count records, then the reference count and ASCII Roman-key/word-ID records.
Runtime uses the packed bytes and primitive offset arrays, lazily decodes word strings,
and performs binary exact lookup, bounded prefix scanning and one-edit probes. It loads
on a worker; the old TSV is loaded only if the packed index is unavailable.

The derived lexicon/index is **CC BY-SA 4.0**, separately licensed from the MIT code.
The full license and attribution ship in `assets/banglish/licenses/`.
`index_metadata.json` records size, counts and the source lexicon SHA-256.

## Original supplements and context

`tools/data/local_words.tsv` has 126 independently authored entries (dialect forms,
names, places and loanwords) with Roman aliases and editorial priorities. No typing-site
dictionary or unlicensed web corpus was copied. The original source TSV is MIT;
its inclusion in the derived reverse index follows that index's CC BY-SA license.

`tools/data/chat_phrases.txt` contains original editorial examples. The same offline
builder creates 51 pruned bigrams in `assets/banglish/bigrams.tsv`, up to four next words
per previous word. These sources and bigrams are MIT project data; their weights are
seed priorities, not observed corpus frequencies. They contain no private user text.

## Accuracy corpus (`app/src/test/resources/banglish_cases.tsv`)

Generated by `tools/build_banglish_lexicon.py` from the word list above plus a hand-written
curated list of the words a learner types first. Every generated Roman spelling is checked to
read back to the same skeleton, so the corpus cannot contain a case that is unreachable by
construction. The original frequency-derived portion follows CC BY-SA 4.0; independently
authored cases are project MIT data. `banglish_release_cases.tsv` adds 122 original cases.
The fixed combined 422 cases are regression data, not an independent quality study.
See [BENCHMARK.md](BENCHMARK.md) for before/after top-1 and visible top-3 measurements.

## Rebuilding

```powershell
python tools/build_banglish_lexicon.py
python tools/build_reverse_index.py
python scripts/banglish_check.py
.\gradlew.bat testDebugUnitTest
```

The legacy builder downloads the source into `build/banglish/` once and writes both the
legacy asset and original test corpus. The reverse builder is fully offline and independent
of fixtures. Preserve the reviewed fixtures for before/after comparisons. The legacy test
also retains its top-1/top-5 floors of 80%/95%; the release test measures top-1/top-3.
